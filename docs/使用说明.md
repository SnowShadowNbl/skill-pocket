# 使用说明

## 用户端（网页）

网页在电脑和手机上自动适配。浏览不需要登录；收藏、评论、添加条目需要登录（邮箱验证码，或配置了小程序时用微信扫码）。

### 主页
- **搜索**：输入关键词或一句话描述需求。配置了 Embedding 时会按意思匹配，不只是按字面。
- **筛选**：按领域大类 / 子类、使用类型筛选，按热度、星标、收录时间排序。
- **新增**：搜索框旁切换到添加模式，可以：
  - 粘贴 **GitHub 链接**：一个仓库里有多个 Skill 时会拆开，让你勾选要收录的；
  - 上传**截图**：单个项目或整张榜单都行，AI 识别后逐条去 GitHub 核实；
  - 粘贴**长文**或文章链接：AI 通读后抽出文中提到的项目；
  - **搜索添加**：描述需求，AI 去 GitHub 搜索并按相关度排序。

  已收录的会提示「已收录」，不会重复添加。添加后右下角显示处理进度。

### 条目详情
功能介绍、安装步骤（命令可一键复制）、GitHub 地址和星标、相关条目。下方「使用日志」可以打分、写评论，支持按住说话的语音输入。

### 榜单
按子分类看日榜和周榜，每个上榜条目都有中文详解。

### 口袋（收藏）
- 收藏的条目可以放进自定义分类，一个条目能放进多个分类；分类可以排序、改名、加 emoji。
- **AI 帮我整理**：给出分类建议，确认后才生效。
- **分享**：把某个分类生成只读链接发给别人。
- **对比**：选几个条目，AI 列出差异和适用场景。
- **导出**：导出成 Markdown 清单或 JSON。

### 我的
资料与头像、登录方式和设备、AI 额度、我提交的反馈、消息通知。

## 管理后台（`/admin`）

超级管理员可以在「管理员」里把已注册用户设为管理员并分配角色，每个角色能看和能改的模块不同：

| 角色 | 适合 |
|---|---|
| 超级管理员 | 唯一账号 `admin`，拥有全部权限，可以任免管理员 |
| 管理员 | 除任免管理员外的全部管理权限 |
| 内容审核 | 条目、评论、分享页、推荐位、黑名单、下架申请等内容相关模块 |
| 客服 | 用户反馈、查看用户、发站内消息 |
| 只读 | 只能查看 |

导出含邮箱的数据、修改用户邮箱、删除用户、任免管理员等高危操作，需要邮箱验证码二次确认。所有管理操作都记录在「操作日志」里。

### 主要模块
- **概览**：待处理事项（待审核条目和评论、新反馈、下架申请、告警）一目了然。
- **内容**
  - 审核：用户提交、需要人工确认的条目。
  - 内容管理：按质量筛选（无封面、无简介、来源失效等），批量改分类、下线、重新提炼、补封面；人工改过的字段会锁定，不会被 AI 覆盖。
  - 评论审核、分享页、推荐位、黑名单、下架申请、分类字典。
- **采集**
  - 采集任务：每日采集的运行记录，可以手动触发。
  - 采集待确认：AI 把握不足、需要人工决定的候选。
  - 收录任务、入库日志：每个条目在每个环节的结果和失败原因。
  - 失效巡检：已下线的条目。
- **用户**
  - 用户管理：搜索、筛选、标签、批量操作。
  - 用户详情：账号与设备、内容与行为、站内消息、管理记录。
  - 账号关系：邮箱账号和微信账号的绑定与合并情况。
  - 用户反馈：工单，可认领、分配、内部备注、用模板回复。
- **AI 与成本**：按功能拆分的调用量和估算成本、用户额度。
- **运营工具**：小范围公告（按标签、注册渠道圈定对象）、首页公告横幅和搜索提示词、分类订阅人数。
- **访客与行为**：访问量、增长、留存、搜索词、内容与 AI 使用分析，可导出 CSV。
- **运行监控**：服务状态、告警、资源用量、邮件与通知、接口健康、前端报错、风控与定时任务、存储与清理。
- **维护工具**：数据一致性检查与修复。

## 每天自动做的事

| 时间 | 内容 |
|---|---|
| 00:05 起 | 每日采集：星标快照 → 计算日榜（周一加算周榜）→ 发现新仓库 → AI 判断是否收录 → 提炼介绍和封面 |
| 凌晨 | 巡检条目原地址，失效的自动下线 |
| 每 10 分钟 | 风控扫描，异常时在后台产生告警 |

采集时间可以在配置里调整（见 [配置说明](配置说明.md)），也可以在后台「运行监控 → 风控与任务」里暂停或手动执行定时任务。
