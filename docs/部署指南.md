# 部署指南

用 Docker Compose 在一台 Linux 服务器上跑起全部服务。

| 容器 | 作用 | 端口 |
|---|---|---|
| `nginx` | HTTPS、反向代理、WebSocket | 对外 80 / 443 |
| `app` | 服务端接口、网页和后台页面、定时任务（单进程） | 内部 8000 |
| `db` | PostgreSQL 16 | 内部 5432 |
| `funasr` | 语音转文字（可选） | 内部 10095 |

## 准备

- **服务器**：建议 4 核 8GB、磁盘 40GB 以上，不需要 GPU。Ubuntu 22.04 / Debian 12 / CentOS Stream 9 都可以。不用语音输入时 2 核 4GB 也能跑。
- **域名**：已解析到服务器 IP。网页必须走 HTTPS，语音输入只能在 HTTPS 下使用。中国大陆的服务器需要先完成域名备案。
- **要申请的服务**：见 [配置说明](配置说明.md)。最少只需要 `SECRET_KEY` 和域名就能跑起来；想用 AI 提炼和邮箱登录，需要提前申请 AI 模型和腾讯云邮件推送。

## 1. 安装 Docker

```bash
curl -fsSL https://get.docker.com | sh
```

国内服务器拉镜像慢的话，在 `/etc/docker/daemon.json` 配置镜像加速，然后 `systemctl restart docker`。

## 2. 获取代码

```bash
sudo git clone https://github.com/SnowShadowNbl/skill-pocket.git /opt/skill-pocket
cd /opt/skill-pocket
```

如果要部署某个固定版本，可以切到对应标签，例如 `git checkout v3.3.75`。

## 3. 填写配置

```bash
cp backend/.env.production.example backend/.env.production
echo "POSTGRES_PASSWORD=$(openssl rand -hex 16)" > .env       # 数据库密码，compose 会读取
python3 -c "import secrets;print(secrets.token_urlsafe(32))"   # 生成 SECRET_KEY
```

编辑 `backend/.env.production`：
- **必填**：`SECRET_KEY` 填上一步生成的字符串；`CORS_ORIGINS` 改成 `https://你的域名`。
- **按需**：AI 模型、Embedding、GitHub Token、腾讯云邮件推送等，每一项的作用和申请方式见 [配置说明](配置说明.md)。

编辑 `deploy/nginx.conf`：把 `example.com` 全部换成你的域名。

> `backend/.env.production` 和 `.env` 里是密钥，已在 `.gitignore` 中排除，不要提交到任何仓库。

## 4. HTTPS 证书

已有证书：把 `fullchain.pem`、`privkey.pem` 放进 `deploy/certs/`。

用 Let's Encrypt 免费证书（先确认 80 端口没被占用）：

```bash
docker run --rm -p 80:80 -v $PWD/deploy/certs:/etc/letsencrypt certbot/certbot certonly --standalone -d 你的域名 --agree-tos -m 你的邮箱 -n
cp deploy/certs/live/你的域名/fullchain.pem deploy/certs/
cp deploy/certs/live/你的域名/privkey.pem deploy/certs/
```

## 5. 启动

```bash
docker compose up -d --build
docker compose ps                  # 等 db、app 变成 healthy
```

不需要语音输入的话：先把 `docker-compose.yml` 里 app 服务下的 `FUNASR_WS_URL` 一行删掉（语音按钮会显示为不可用），再只启动三个服务：`docker compose up -d --build db app nginx`。

启用语音输入时，FunASR 首次启动会把约 1GB 的模型下载到项目的 `model/` 目录，用 `docker compose logs -f funasr` 查看，出现 listen 字样即就绪。

## 6. 设置超级管理员

超级管理员的账号名固定为 `admin`。为了不在服务器上留明文密码，第一次用「首次登录」在页面上设置密码：

```bash
docker compose exec app python -m app.cli open-admin-setup 2    # 打开 2 小时的首次登录窗口
```

然后打开 `https://你的域名/admin`，账号填 `admin`、密码留空，点登录。进入后按提示设置密码，设置完成后首次登录入口永久关闭。

之后可以在后台「管理员」里把其他已注册的用户设为管理员，并分配角色。

## 7. 验证

- [ ] `https://你的域名/api/health` 返回 `{"ok":true}`
- [ ] 首页能打开，搜索和分类筛选正常
- [ ] 后台「采集任务」显示 GitHub Token 状态和下次运行时间
- [ ] 后台「运行监控 → 服务状态」里各项检查正常
- [ ] 配置了邮件的话，用邮箱验证码能登录
- [ ] 刚部署时库是空的：可以在网页上用「新增」添加几个 GitHub 项目，或在后台「采集任务」手动跑一轮采集

## 日常运维

```bash
docker compose logs -f app            # 应用日志
docker compose restart app            # 改了 .env.production 后重启
docker compose exec db pg_dump -U skillhub skillhub | gzip > backups/$(date +%F).sql.gz   # 手动备份数据库
```

**每日备份**：后台「运行监控」里的备份状态读取 `backups/` 目录里的 `*.sql.gz`。建议加一条 crontab（`crontab -e`）：

```
30 4 * * * cd /opt/skill-pocket && mkdir -p backups && docker compose exec -T db pg_dump -U skillhub skillhub | gzip > backups/$(date +\%F).sql.gz && find backups -name '*.sql.gz' -mtime +14 -delete
```

**证书续期**：Let's Encrypt 证书 90 天有效，续期后把新证书拷到 `deploy/certs/`，再 `docker compose restart nginx`。

## 升级到新版本

```bash
cd /opt/skill-pocket
docker compose exec -T db pg_dump -U skillhub skillhub | gzip > backups/pre-upgrade-$(date +%F).sql.gz   # 先备份
git fetch --tags && git checkout v新版本号
docker compose up -d --build app
```

数据库结构会在应用启动时自动升级。每个版本的改动见 [CHANGELOG](../CHANGELOG.md)。

## 注意事项

- **`app` 只能跑 1 个进程**：定时采集在进程内运行，多进程会重复采集。
- 数据库和封面图在 Docker 卷里（`pgdata`、`appdata`），语音模型在项目的 `model/` 目录。`docker compose down` 不会删除它们，**不要加 `-v`**。
- 每天 00:05 开始自动采集（可在配置里改时间），升级和重启尽量避开采集时段。
