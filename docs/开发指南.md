# 开发指南

## 本地启动

后端（端口 8001，默认使用 SQLite，不需要装数据库）：

```bash
cd backend
python -m venv .venv
.venv/bin/pip install -r requirements.txt -r requirements-dev.txt     # Windows 用 .venv\Scripts\
.venv/bin/python -m app.cli init-env          # 生成 backend/.env 和随机 SECRET_KEY
.venv/bin/python -m app.cli set-password      # 设置管理员 admin 的密码
.venv/bin/python -m uvicorn app.main:app --port 8001
```

本地开发可以在 `backend/.env` 里设 `AUTH_DEV_CODES=true`，邮箱验证码会直接显示在页面上，不需要配置邮件服务。

前端（端口 5173，`/api`、`/media` 自动代理到 8001）：

```bash
cd frontend
npm install
npm run dev
```

- 用户端：http://localhost:5173
- 管理后台：http://localhost:5173/admin

## 没有 FunASR 时调试语音

```bash
cd backend
.venv/bin/python scripts/mock_asr.py
```

然后在 `backend/.env` 里设 `FUNASR_WS_URL=ws://127.0.0.1:10095`。

## 测试

```bash
cd backend
.venv/bin/python -m pytest -q tests
```

设置 `TEST_DATABASE_URL` 可以在 PostgreSQL 上跑同一套测试。

## 数据库变更

表结构在 `backend/app/models.py`，变更脚本在 `backend/migrations/versions/`（Alembic）。改表时新增一个迁移文件，应用启动时会自动升级。

## 约定

- **需要判断的地方交给 AI**（`app/services/judge.py`）：收录、分类、搜索理解、长文抽取等，规则只在 AI 不可用时兜底。
- **管理操作要留痕**：后台的写操作要求填原因，并通过 `services/activity.py` 记录操作前后的值。
- **界面**：遵循 `design-system/MASTER.md`，使用项目里已有的组件，不直接使用浏览器原生的下拉框、日期选择等控件。
- **版本记录**：每个版本在 `backend/app/changelog.py` 里加一条更新日志，网页右上角的「更新日志」会显示。
