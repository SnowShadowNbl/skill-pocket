# 配置说明

所有配置写在 `backend/.env.production`（模板见 `backend/.env.production.example`）。这些值都是密钥或私有信息，**只放在你的服务器上，不要提交到 Git**。改完后执行 `docker compose restart app` 生效。

## 一览

| 配置 | 用途 | 不填会怎样 |
|---|---|---|
| `SECRET_KEY` | 签名登录会话 | **必填**，否则无法启动 |
| `CORS_ORIGINS` | 允许访问接口的域名 | **必填** |
| `AI_BASE_URL` / `AI_API_KEY` / `AI_TEXT_MODEL` | AI 提炼、分类、收录判断、搜索理解、对比、截图识别 | 用规则代替，介绍和分类质量明显下降；截图识别、AI 搜索、对比不可用 |
| `EMBEDDING_API_KEY` 等 | 语义搜索 | 只用关键词搜索 |
| `GITHUB_TOKEN` | 读取 GitHub 仓库信息、每日采集 | 每小时只有 60 次请求，采集很快被限流 |
| `SES_*` | 发送邮箱验证码 | 无法用邮箱注册和登录（管理员仍可用密码登录） |
| `WX_APPID` / `WX_SECRET` | 网页微信扫码登录 | 不显示微信登录 |
| `CONTACT_EMAIL` | 页脚「联系站长」 | 不显示 |

## 必填

### SECRET_KEY
随机长字符串，用来签名登录会话。生成方法：

```bash
python3 -c "import secrets;print(secrets.token_urlsafe(32))"
```

部署后不要随意更换，否则所有人都需要重新登录。

### CORS_ORIGINS
你的访问地址，例如 `https://skill.example.com`，多个用英文逗号分隔。

### ADMIN_PASSWORD_HASH
推荐留空，部署后用「首次登录」在页面上设置超级管理员密码（见 [部署指南](部署指南.md) 第 6 步）。

## AI 模型

Skill Pocket 把需要判断的工作都交给大模型：是否收录、分类、写中文介绍和安装步骤、理解搜索意图、识别截图、对比条目、整理收藏。可以接入任何**兼容 OpenAI 接口**的服务。截图识别要求模型支持图片输入。

| 配置 | 填什么 |
|---|---|
| `AI_BASE_URL` | 接口地址，例如 `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| `AI_API_KEY` | 服务商发给你的 API Key |
| `AI_TEXT_MODEL` | 模型名，例如 `qwen-plus` |

**去哪里申请**（任选一家）：
- **阿里云百炼**：登录 [阿里云百炼控制台](https://bailian.console.aliyun.com/)，开通服务后在「API-KEY 管理」创建 Key。接口地址填 `https://dashscope.aliyuncs.com/compatible-mode/v1`，模型可选 `qwen-plus`；要用截图识别，可选支持视觉的通义千问模型。
- **DeepSeek**：在 [DeepSeek 开放平台](https://platform.deepseek.com/) 创建 API Key，接口地址 `https://api.deepseek.com/v1`。
- 其他兼容 OpenAI 接口的服务同理，按服务商文档填写地址和模型名。

**费用**：按用量计费。后台「AI 与成本」可以看到每个功能的调用量和成本：每次调用按当时的单价记下真实成本，单价表在后台「AI 与成本」里可以改（默认按 DeepSeek 的峰谷报价）。

### 用户额度

用户发起的 AI 操作（智能对比、搜索添加、截图和长文识别、新增条目的提炼）会消耗额度，余额用完后不能再发起，需要管理员在后台「AI 额度」里给用户充值或调整。管理员账号不受额度限制。

- **没有配置微信登录**（`WX_APPID` / `WX_SECRET` 留空，自部署通常如此）：每个账号第一次用到 AI 时直接发放免费额度，默认 50 万，可在后台「AI 额度」里改。
- **配置了微信登录**：免费额度只发给绑定了微信的账号（微信登录的账号，或邮箱账号绑定微信后），**每个微信只发一次**，解绑再绑、换账号都不会重复发。纯邮箱账号会被提示先绑定微信。
- 额度用完时，网页会弹窗提示联系管理员。弹窗里显示的**联系微信号和名片二维码**在后台「AI 额度」里设置，不设置就不显示。

## 语义搜索（Embedding）

| 配置 | 填什么 |
|---|---|
| `EMBEDDING_API_KEY` | API Key |
| `EMBEDDING_BASE_URL` | 默认阿里云百炼：`https://dashscope.aliyuncs.com/compatible-mode/v1` |
| `EMBEDDING_MODEL` | 默认 `text-embedding-v4`（1024 维） |

用阿里云百炼的话，`EMBEDDING_API_KEY` 可以和上面的 `AI_API_KEY` 用同一个 Key。配好后新收录的条目会自动生成向量；部署前已有的条目，用管理员身份调用一次 `POST /api/admin/search/backfill` 即可补算。

## GitHub Token

用于读取仓库信息、README、星标数，以及每日自动采集。

**申请**：GitHub → 右上角头像 → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token。
- Repository access 选 **Public repositories (read-only)**；
- 不需要勾选任何额外权限。

把生成的 Token 填到 `GITHUB_TOKEN`。有效期到了要重新生成。

## 邮件：腾讯云邮件推送 SES

用户用「邮箱 + 验证码」注册和登录，验证码通过腾讯云邮件推送发送。

**申请步骤**：
1. 登录 [腾讯云邮件推送控制台](https://console.cloud.tencent.com/ses) 开通服务。
2. **发信域名**：添加一个你自己的域名（建议用子域名，例如 `mail.example.com`），按提示在域名解析里添加 SPF、DKIM、DMARC 等记录，等待验证通过。
3. **发信地址**：在这个域名下创建发信地址，例如 `noreply@mail.example.com`，填到 `SES_FROM`。
4. **邮件模板**：创建一个验证码模板，正文里用变量 `{{code}}` 表示验证码，提交审核。审核通过后把模板 ID 填到 `SES_TEMPLATE_ID`。
5. **API 密钥**：在 [访问管理 → API 密钥](https://console.cloud.tencent.com/cam/capi) 创建密钥。建议新建一个只授权「邮件推送」的子用户，用它的 SecretId / SecretKey 填到 `SES_SECRET_ID` / `SES_SECRET_KEY`。
6. `SES_REGION` 一般填 `ap-guangzhou`（香港等地域按控制台显示填写）。

模板审核通过前，登录框会提示用户改用其他方式登录。后台「运行监控 → 邮件与通知」可以看到每封邮件的发送结果和本月用量。

`AUTH_DEV_CODES` 只用于本地开发（验证码直接显示在页面上），**生产环境必须为 `false`**。

## 微信登录（可选）

网页上的「微信扫码登录」和已登录账号的「绑定微信」都依赖一个你自己的**微信小程序**：用户用微信扫小程序码，在小程序里确认。本仓库不包含小程序代码，如果你没有自己的小程序，留空即可，网页只显示邮箱登录。配置了微信登录后，免费 AI 额度只发给绑定了微信的账号，见上文「用户额度」。

| 配置 | 填什么 |
|---|---|
| `WX_APPID` / `WX_SECRET` | [微信公众平台](https://mp.weixin.qq.com/) → 开发管理 → 开发设置里的 AppID 和 AppSecret |
| `WX_QR_ENV` | 扫码打开小程序的哪个版本：`release` 正式版 / `trial` 体验版 / `develop` 开发版 |

想在网页顶栏显示「小程序」入口，把小程序码图片放到 `frontend/public/mp-qrcode.jpg` 后重新构建；没有这张图时入口自动隐藏。

## 语音输入（可选）

评论框里的「按住说话」使用开源的 FunASR 模型，在你自己的服务器上运行，不需要申请任何 Key。由 `docker-compose.yml` 里的 `funasr` 服务提供，首次启动自动下载模型（约 1GB）。不需要时见 [部署指南](部署指南.md) 第 5 步。

## 每日采集

| 配置 | 默认 | 说明 |
|---|---|---|
| `CRAWL_ENABLED` | `true` | 是否每天自动采集 |
| `CRAWL_TZ` | `Asia/Shanghai` | 时区 |
| `CRAWL_START` / `CRAWL_END` | `00:05` / `08:00` | 采集时间窗口，没做完的留到第二天 |
| `RANK_TOP_N` | `10` | 每个子分类的榜单条数 |
| `MAX_NEW_REPOS_PER_RUN` | `60` | 每轮最多判定的新仓库数 |
| `SKILL_SPLIT_MAX` | `15` | 一个仓库里的 Skill 超过这个数，就当作合集只收一条 |
| `AWESOME_LISTS` | 空 | 额外要扫描的 awesome 清单仓库，逗号分隔，例如 `owner/awesome-xxx` |

## 其他

| 配置 | 说明 |
|---|---|
| `CONTACT_EMAIL` | 页脚显示的站长联系邮箱，留空不显示 |
| `ADMIN_SESSION_MINUTES` | 管理员密码登录的会话时长（分钟） |

后台「运营工具」「运行监控 → 风控与任务」等页面里还有一些可以直接在页面上调整的设置（例如验证码频率限制、首页公告横幅），不需要改配置文件。
