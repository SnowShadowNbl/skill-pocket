# Skill Pocket · 你的 Skill 口袋

Skill Pocket 是一个收录、检索和管理 **AI Skill、AI 模型、工具与开源项目** 的站点，可以私有化部署。它每天自动从 GitHub 发现新项目，用 AI 整理成中文介绍和安装步骤，生成分类榜单。用户可以搜索、收藏、评论，管理员在后台审核内容、管理用户和监控运行情况。

本仓库包含**服务端**、**网页端**（电脑和手机自适应）和**管理后台**，采用 [AGPL-3.0](LICENSE) 许可证。

## 三大核心能力

1. **GitHub 的中文中转站**：用一句中文说出需求，AI 转换成多组英文搜索词去 GitHub 搜索，并逐个打分过滤；英文结果再转换成中文简介、详细介绍和安装步骤。
2. **一个口袋统一收藏**：在短视频、文章里看到好用的 Skill 或模型，截个图就能识别并收藏；也能用网址、名称、一句话描述来搜索和添加。
3. **AI 智能对比**：几个相似的 Skill 或模型，按核心能力、上手难度、活跃度、成本、许可证等 9 个维度对比，并按使用场景给出推荐。

详细介绍见 [为什么用 Skill Pocket](docs/为什么用SkillPocket.md)。

## 它还能做什么

**给用户**
- **找工具**：按领域（13 大类）和使用类型（Agent 技能 / AI 模型 / 工具应用 / 开发资源 / 项目 Demo）筛选。
- **看榜单**：按子分类出日榜和周榜，每个上榜条目有中文详解。
- **收藏整理**：自定义收藏分类，可让 AI 帮你整理；收藏分类可以生成只读分享链接，也能导出成 Markdown 或 JSON。
- **评论与评分**：给条目打分、写使用日志，支持按住说话的语音输入。

**给管理员**（`/admin`）
- **内容**：审核新条目和评论，批量处理，设置推荐位，管理黑名单和原作者的下架申请，治理分类。
- **用户**：用户列表和详情、标签、邮箱和微信账号关系、AI 额度、反馈工单、站内消息。
- **运行**：采集任务和入库日志、服务状态、告警、备份、邮件记录、接口健康、前端报错、风控和定时任务。
- **数据**：访问统计、增长、内容、搜索和 AI 用量分析，以及公告和首页运营位。
- **权限**：五种管理员角色（超级管理员 / 管理员 / 内容审核 / 客服 / 只读），高危操作需要邮箱验证码二次确认，所有管理操作都有记录。

**自动运行**
- 每天凌晨自动采集：给已收录仓库拍星标快照，计算榜单，发现新仓库，由 AI 判断是否收录并提炼介绍。
- 每天巡检条目原地址，已失效的自动下线。

## 技术栈

| 部分 | 技术 |
|---|---|
| 服务端 | Python 3.12 · FastAPI · SQLAlchemy · Alembic · APScheduler |
| 数据库 | PostgreSQL 16（本地开发可用 SQLite） |
| 网页端与后台 | Vue 3 · Vite · Tailwind CSS 4 |
| 语音识别（可选） | FunASR 开源模型，CPU 即可 |
| AI | 任意兼容 OpenAI 接口的大模型服务 |
| 部署 | Docker Compose（Nginx + 应用 + PostgreSQL + FunASR） |

## 快速开始

- **部署到服务器**：见 [部署指南](docs/部署指南.md)，一台 4 核 8GB 的 Linux 服务器加一个域名即可。
- **它能帮你解决什么**：见 [为什么用 Skill Pocket](docs/为什么用SkillPocket.md)。
- **要申请哪些服务、填哪些配置**：见 [配置说明](docs/配置说明.md)。
- **怎么用**：见 [使用说明](docs/使用说明.md)。
- **本地开发**：见 [开发指南](docs/开发指南.md)。

最少需要填的配置只有 `SECRET_KEY` 和域名。AI 模型、邮件、GitHub Token 都是可选的，不填时对应功能会降级或关闭，详见配置说明。

## 目录结构

```
backend/           服务端（FastAPI）
  app/routers/     接口
  app/services/    业务逻辑（采集、AI 判断、搜索、邮件等）
  app/models.py    数据表
  migrations/      数据库版本（启动时自动升级）
  tests/           测试
frontend/          网页端和管理后台（Vue 3）
  src/             用户端网页，入口 index.html
  src/admin/       管理后台，入口 admin.html（访问 /admin）
deploy/            Nginx 配置
design-system/     设计规范
model/             语音识别模型下载脚本
docker-compose.yml 一键部署
```
