# 后台手机布局规范

后台每一页都要在 390 宽度下能看待办、审核、回复反馈。验收用 390 和 1280 两个宽度。

## 断点
- 手机：< 640px（Tailwind `sm`），桌面：≥ 640px。侧栏在 < 1024px（`lg`）收成抽屉。
- 代码里判断手机用 `useMobile()`；样式优先用 `sm:` / `lg:` 前缀，不要手写媒体查询。

## 点击区与溢出
- 触屏设备（`pointer: coarse`）上，按钮、输入框、下拉、侧栏条目至少 40px；`admin.css` 已统一处理，新控件照着做。
- 勾选框用 `ACheckbox`（点击区 40px）；不要用原生 checkbox / select / date / confirm。
- 页面不能横向溢出。长文本加 `truncate` 或 `break-words`，容器加 `min-w-0`。

## 列表
- 一律用 `ATable`，不要手写 `<table>`。每列用 `mobile` 指定手机卡片里的位置：
  - `title`：标题行（头像 / 名称）；`sub`：标题下小字；
  - `meta`：底部一排小字，`mlabel: true` 时带上列名；
  - `action`：卡片右上角操作；`hide`：手机上不显示（IP、注册时间等次要信息）。
- 一张卡片只保留判断和操作需要的信息，其余进详情抽屉。
- 点整张卡片打开详情（`clickable` + `@row-click`），卡片内的按钮要 `@click.stop`。

## 筛选
- 用 `useQueryFilters` + `AFilterBar`：手机上只露出搜索框和「筛选 · N」按钮，其余条件折叠。
- 条件多于 3 个的页面，把最常用的放进搜索框，不要在手机上平铺。

## 详情与弹层
- 详情一律用 `ADrawer`（手机全屏），地址里带 `?id=`；手机返回键即关闭。
- 底部固定的东西（`ABulkBar`、弹层底部按钮）要加 `pb-[max(12px,env(safe-area-inset-bottom))]`。
- 原因弹窗在手机上是底部弹层，结果面板全屏。

## 批量操作
- `useSelection` + `ABulkBar` + `AResultPanel`：手机上操作按钮自动换行，不要再加第二个固定栏。
