# Skill Pocket · 设计系统（MASTER）

风格依据 [ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) 的风格库，经 5 个 demo 对比后选定 **方案 B「极光玻璃」**（Aurora UI + Glassmorphism，浅色）。demo 原型保存在 `frontend/public/demos/`。

## 风格要点

- 背景：三团柔和色块（靛 `#a5b4fc` / 粉 `#f9a8d4` / 青 `#99f6e4`）大面积模糊，18–26s 缓慢漂移
- 表面：半透明白 + 背景模糊（`.glass` 58% / `.glass-strong` 82%），1px 白色描边，圆角 14–28px
- 强调：靛→粉渐变（`#6366f1 → #ec4899`）用于主按钮、选中态、序号、统计数字
- 图标：SVG（Lucide 线性，stroke 2），不用 emoji

## 动效

| 场景 | 做法 | 时长 / 曲线 |
|---|---|---|
| 卡片 / 区块入场 | `v-reveal`：透明 + 下移 24px + 模糊 4px → 清晰，错落 55ms | 700ms `cubic-bezier(.22,1,.36,1)` |
| 卡片悬停 | 上浮 6px、背景变实、靛色投影 | 400ms |
| 无封面图标 | 轻微上下漂浮，色团悬停放大 | 4s 循环 |
| 主按钮 | 悬停扫光、按下缩到 0.96 | 700ms / 300ms |
| 分段控件 | 渐变滑块平移到选中项 | 500ms |
| 详情 | 抽屉：手机底部弹出、桌面右侧滑入，遮罩模糊 | 600ms 进 / 350ms 出 |
| 统计数字 | 从 0 滚动到目标值 | 1100ms ease-out |
| 首次加载 | 骨架屏 + 微光扫过 | 1.4s 循环 |
| 页面切换 | 淡入 + 上移 12px | 300ms |

系统开启“减少动态效果”时全部关闭（`prefers-reduced-motion`）。

## 字体与布局

- 系统中文字体栈，不加载外部字体（国内访问稳定）
- 断点：<640 手机 / 640–1024 平板 / ≥1024 桌面；列表 1 / 2 / 3（超宽 4）列
- 手机：底部玻璃标签栏（首页 / 加入 / 分类），选中项有胶囊底
- 触控目标 ≥ 44px；输入框手机端 16px 字号（避免 iOS 缩放）

## 检查清单

- [ ] 正文对比度 ≥ 4.5:1（玻璃底上用 `ink` / `ink-2`，不用浅灰）
- [ ] 渐变背景上的文字一律白色加粗
- [ ] 键盘焦点可见（2px 主色描边）
- [ ] 375 / 768 / 1024 / 1440 宽度无横向滚动
- [ ] 新增动效同时考虑 reduced-motion
